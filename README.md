# Sistema de Cadastro de Usuários

Sistema de cadastro e gerenciamento de usuários desenvolvido em Python,
com foco em organização de código, lógica de programação e boas práticas
de desenvolvimento.

## 🚀 Funcionalidades

- [x] Cadastro de usuários
- [x] Listagem de usuários
- [ ] Busca de usuários
- [ ] Edição de usuários
- [ ] Exclusão de usuários
- [ ] Validação de dados
- [ ] Persistência dos dados em JSON

## 🛠️ Tecnologias

- Python
